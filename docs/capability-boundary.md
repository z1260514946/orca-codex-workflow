# 能力边界

## 1. 已验证能力

本公开案例和流程材料覆盖以下受监督步骤：

- Task 创建的流程记录方式。
- Worker 调度的角色和交接约定。
- Worktree 隔离的协作方式。
- Reviewer 验证和结论记录。
- 从候选版本到 Delivery 的交付闭环说明。

这些内容表示流程材料中有对应示例或模板，不表示本仓库提供了实现这些能力的运行时服务。

## 2. 未验证能力

以下能力不应从本仓库推断为已实现：

- 自动生产发布。
- 自动权限批准。
- 无人监督运行。
- 自动恢复、无限并发或成本控制。
- 跨组织的凭证和数据治理。

## 3. 原则

**Agent 执行，人类决策。**

Agent 可以在明确范围内执行任务和生成证据，但人类仍负责权限、敏感数据访问、外部写入、候选合并和发布决定。无法核实的能力应标记为待验证或 `BLOCKED`，不能用文案替代运行证据。
