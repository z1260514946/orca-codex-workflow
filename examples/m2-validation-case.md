# 脱敏 M2 验证案例

## 用途

本案例展示如何引用历史验收，而不把历史结果包装成当前公开仓库的通过证明。

## 记录方式

- 原冻结候选：`5869018aa824e9b5076e6b8f1628759f245555f5`
- 历史结论：M2 PASS。
- 公开发布提交：以本仓库实际生成的完整 SHA 为准，与原候选分开记录。
- 公开验证范围：本文档、模板、配置示例的内容、链接、示例一致性和字符卫生。

## 边界

不复制内部 Run/Task/Worker 标识、dispatch capability、运行日志、真实路径、凭证、业务数据或原始 stdout/stderr。历史 M2 PASS 不能替代本发布提交的公开内容检查。
